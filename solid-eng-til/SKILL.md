# 솔리드 이엔지 학습 기록

현재 대화에서 공부한 내용과 사용자가 지정한 메모, 파일, 코드, 명령어를 바탕으로 작성한다. 사용자가 실제로 공부하거나 실행한 내용과 설명을 위해 새로 만든 예시를 구분한다. 학습 근거가 전혀 없으면 주제나 자료를 요청한다.

## 기록 위치

[리눅스 → 쿠버네티스 까지](https://app.notion.com/p/421c2c49a25080a98096cc715b1c122c?source=copy_link), 페이지 ID `421c2c49-a250-80a9-8096-cc715b1c122c`.

Notion 도구로 지정된 부모 페이지를 확인한 뒤, 학습 기록마다 그 아래에 하위 페이지를 하나 만든다. 제목은 `YYYY.MM.DD (짧은 학습 주제)` 형식으로 쓴다. 예시는 `2026.11.20 (쿠버네티스 Service)`다. 사용자가 학습 날짜를 알려주면 그 날짜를 쓰고, 생략하면 사용자 시간대의 오늘 날짜를 쓴다.

하위 페이지의 본문에는 아래 네 항목을 넣는다. 기존 기록의 수정을 요청받으면 지정된 부모 아래의 해당 하위 페이지만 수정한다. 접근이나 쓰기에 실패하면 저장되지 않았음을 알린다. 저장 후에는 하위 페이지의 부모, 제목, 본문 항목 네 개와 코드 블록을 확인하고 하위 페이지 링크를 전달한다.

## 본문 양식

아래 제목과 순서를 그대로 사용한다.

### 1. 오늘 배운 내용

- 배운 개념, 동작 방식, 실습 내용을 주제별로 정리한다.
- 예시 코드를 코드 블록으로 반드시 넣고, 코드가 보여 주는 동작을 짧게 설명한다. 리눅스나 쿠버네티스 주제에는 셸 명령어나 YAML 설정을 사용할 수 있다. 원본에 코드가 없으면 학습 개념을 보여 주는 짧은 코드를 작성하고 `학습용 예시`로 표시한다.

### 2. 어려울 수 있는 점

- 이해하거나 실습할 때 막히기 쉬운 부분과 확인할 지점을 간략하게 적는다.

### 3. 헷갈린 부분

- 대화에서 사용자가 실제로 헷갈린 부분만 기록한다. 어떻게 이해했는지와 바로잡은 내용이 확인되면 함께 적는다. 해당하는 내용이 없으면 `없음`이라고 쓴다.

### 4. 이 배운 내용으로 할 수 있는 것

- 배운 내용을 회사 업무에서 어떤 작업이나 상황에 적용할 수 있는지 구체적으로 적는다.
